## Proje Hakkında

Bu proje, insanlık tarihinin en önemli bilimsel başarılarından biridir. Kedilerin aslında evrenin en derin sırlarını bildiğini, ancak sadece miyavlayarak anlattıklarını ispatlar.

**Uyarı:** Bu simülatör o kadar gerçekçidir ki, programı çalıştırdıktan sonra kediniz size farklı gözle bakabilir. Sorumluluk kabul etmiyoruz.

## Özellikler

- **Gerçekçi Kedi Cevapları**: Rastgele seçilen, tamamen anlamsız ama derin cevaplar.
- **Yavaş Yazma Efekti**: Çünkü kediler acele etmez, kod da etmemeli.
- **Sonsuz Olmayan Sonsuzluk**: 5 tur sohbet. Daha fazlası için yeniden çalıştır (sonsuz döngü çok tehlikeli).
- **Felsefi Derinlik**: Hayatın anlamından çorap kaybolmasına kadar her şey.
- **Gizli Mesajlar**: Kodun içinde gizli sırlar var. Bulmaya çalış.

## Nasıl Çalıştırılır?

```bash
python kedi_sohbet.py
```

Python 3 yüklü olmalı. Başka bir şey gerekmez. Kediniz bile gerekmez ama olsa daha iyi.
